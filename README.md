## Penjelasan Langkah Pengerjaan
1. Membuat struktur folder `Lab2Web` beserta subfolder `media`.
2. Menyusun kerangka halaman menggunakan elemen **Semantic HTML** (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`)[cite: 3].
3. Menerapkan struktur tabel lengkap dengan atribut `border`, `<thead>`, `<tbody>`, `<tfoot>`, serta `colspan`[cite: 1].
4. Membuat form registrasi interaktif menggunakan berbagai jenis elemen input (`text`, `email`, `password`, `number`, `radio`, `checkbox`, `select`, dan `textarea`)[cite: 2, 3].
5. Menambahkan atribut validasi HTML dasar seperti `required`, `minlength`, `min`, dan `max`[cite: 3].
6. Menyisipkan elemen pemutar multimedia (`<audio>` dan `<video>` dengan atribut `controls`)[cite: 3].
7. Menyelesaikan proyek mini berupa halaman `biodata.html`[cite: 6].
